# Portfolio Testowe - Platforma E-commerce wlep.pro | Audyt dostępności cyfrowej podstrony wyszukiwania: Pałac Młodzieży w Warszawie wg standardu WCAG 2.1

### Opis Projektu
Realizacja pełnego cyklu testowego dla aplikacji webowej wraz z audytem dostępności cyfrowej. Projekt obejmował analizę wymagań, projektowanie testów oraz weryfikację końcową.

### Zakres prac:
* **Analiza wymagań i projektowanie testów**: Przygotowanie strategii sprawdzania platformy.
* **Dokumentacja testowa**: Stworzenie profesjonalnych scenariuszy i przypadków testowych.
* **Raportowanie**: Rejestracja błędów oraz przygotowanie raportu z wykonanych testów.
* **Audyt WCAG 2.1**: Weryfikacja dostępności cyfrowej pod kątem standardów dla osób z niepełnosprawnościami.

### Narzędzia:
* DevTools, Lighthouse, Axe, Wave, W3C Validator, Colour Contrast Analyser.
